    Try to hack it

    Brute-forcing a 256-bit invisible ID at 1 trillion guesses/second would take about 10⁶³ years — far longer than the age of the universe. There is also no username list to enumerate and no server to attack.

    Honest note: invisibility is one layer, not magic. This offline app also uses SHA-256 ID hashing, PBKDF2 passphrase hashing, a random salt, and generic errors. Losing both the ID and the passphrase means the vault is unrecoverable — there is no email reset, by design. See SECURITY.md in the repo.
