Encrypted backup

Export downloads a JSON file encrypted with AES-GCM. Passwords are never exported in plaintext. You need the backup passphrase to import it again. This backs up your app logins (stored in this browser); server notes are backed up separately.

Social apps hub

Store logins for Facebook, Instagram, YouTube, WhatsApp, X, Gmail — or any app. Launch opens the app's site; the vault itself never logs you in (each app still needs its own sign-in). App logins are stored in this browser only, and only shown after you unlock with your invisible ID.

    Secure notes

      Try to hack it

      Brute-forcing a 256-bit invisible ID at 1 trillion guesses/second would take about 10⁶³ years — far longer than the age of the universe. There is also no username list to enumerate and no /users/:id endpoint.

      Honest note: invisibility is one layer, not magic. This app also uses bcrypt, rate limiting, hashed IDs, constant-time compare and generic errors. See SECURITY.md in the repo.
